Instrument 04

Decision Wheel

Uma roda simples para decisões de baixo risco. Quando a hesitação já custa mais do que a escolha, esta ferramenta ajuda a desbloquear.

Use case

Isto não é para decisões sérias de vida. É para escolhas pequenas: opções, variações, caminhos equivalentes ou desempate rápido.

  • Baixa fricção
  • Resultado imediato
  • Visual claro
  • Sem ruído desnecessário

Input

Usa entre 2 e 12 opções. Mantém as entradas curtas para a leitura ser limpa.

Method note

Como usar bem esta roda

Esta ferramenta serve para desbloquear micro-decisões, não para terceirizar juízo. Se a decisão for importante, pensa. Se for equivalente, roda.

  • Boa para desempate e variações pequenas.
  • Não uses para decisões graves.
  • Se o resultado te irritar, talvez já saibas o que realmente queres.
